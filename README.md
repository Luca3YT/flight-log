# 搭乗記録アプリ

iPhoneのホーム画面から起動する記録アプリです。機内のオフラインでも動き、記録は端末に保存され、電波が戻るとスプレッドシートにも自動で追記されます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面とデザイン |
| `app.js` | アプリ本体 |
| `data.js` | 空港・航空会社・座席表・日本地図のデータと、これまでの49便 |
| `sw.js` | オフライン用キャッシュ |
| `manifest.webmanifest` / `icon-*.png` | ホーム画面用の設定とアイコン |
| `gas/Code.gs` | スプレッドシート側に貼る同期スクリプトの控え（合言葉は入っていません） |

## 1. アプリを置く（GitHub Pages、無料）

1. GitHubで新しい **public** リポジトリを作る（例 `flight-log`）
2. `gas` フォルダ以外のファイルをすべてルートに置いて push
3. Settings → Pages → Source を `Deploy from a branch`、`main` / `/(root)` で Save
4. 1〜2分後、`https://<ユーザー名>.github.io/flight-log/` が開けるようになる
5. iPhoneでそのURLを開き、共有ボタン → **ホーム画面に追加**（SafariでもChromeでも可）

記録は端末に入るので、リポジトリがpublicでも他人に見られるのは空のアプリだけです。

## 2. スプレッドシートと同期する

1. 今の搭乗記録スプレッドシートを開く → 拡張機能 → **Apps Script**
2. 最初からある中身を消して `gas/Code.gs` を貼り付ける
3. 1行目付近の `TOKEN` を自分だけの合言葉に書き換えて保存
4. 右上の **デプロイ → 新しいデプロイ** → 種類で「ウェブアプリ」
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**全員**
5. 承認画面が出たら自分のアカウントで許可（「安全ではないページ」と出たら「詳細」→「移動」）
6. 表示された `/exec` で終わるURLをコピー
7. アプリの **設定 → スプレッドシート同期** にURLと合言葉を入れて「保存して接続を確認」

「接続しました。シートに◯行あります」と出れば完了です。

### シート側で起きること

- 書き込み先は `搭乗記録` シート。見出し（日付・出発・到着・路線・機材・機体記号・備考）を探して、その列に書きます
- `航空会社` `座席` `窓` `便名` `ID` の列がなければ右端に自動で追加します
- `#` 列や `路線` 列に数式（ARRAYFORMULAを含む）がある場合は、数式を壊さずにそのまま使います
- アプリで編集・削除すると、シートの同じ行も更新・削除されます

### 最初にやっておくとよいこと

アプリには flight_log_gs の49便（2024/07/21〜2026/10/03）が最初から入っています。

- 設定 →「全件をシートに送り直す」を押すと、シートの既存行に ID が振られて、以後アプリと紐づきます。日付・区間・機体記号が一致する行は上書きされるだけで、重複はしません
- アプリにない便をシートに手入力した場合は、設定 →「シートから受信」でアプリに入ります
- 同期を設定していなくても、シートで範囲をコピーして 設定 →「スプレッドシートから取り込む」に貼れば取り込めます（CSVファイルも可）

### Code.gs を直したとき

デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン「新バージョン」→ デプロイ。こうするとURLが変わりません（「新しいデプロイ」を作るとURLが変わります）。

## 3. 窓位置ログを移す

前の窓位置ログアプリで「コードで書き出す」を押して出る1行（`v1|g=10K|r=11A,...`）をコピーし、
新アプリの **窓位置** タブで機材「JALグループ B737-800 V35 / V36」を選んで、下の欄に貼って「読み込む」。

なお、5月時点のメモ（10A 窓なし、10K 真横、11・16・18A・19・21・27・28 見にくい）は最初から入れてあります。その後に判定を増やしていたら、上の手順で上書きしてください。

## 主な機能

- **記録**：日付 → 航空会社 → 区間 → 機体記号 → 機材 → 座席 → 備考 の順に入力。券面がその場で埋まっていきます
- **機体記号から機材を自動入力**：前回の記録、なければ記号のパターン（JA3xxJ → B737-800 など）から判定。機材画面で手動で直せます
- **編集**：記録をタップ → 編集。日付の画面から始まり、右上の「確認へ」で最後まで飛べます
- **統計**：路線マップ（飛んだ範囲／日本全体）、実績24種、機体記号・路線・機材・空港のランキング
- **振り返りカード**：統計タブから。年間・半年・月間の画像を作って保存・共有できます
- **起動アニメーション**：画面をタップするとスキップ。設定でオフにもできます

## 座席表について

- JAL（A350・767・737）、ANA（737・787の一部）、スカイマーク 737-800 は各社の公式座席表の列番号・非常口・窓なし席を元にしています
- それ以外は「目安」表示の代表的な配置です。実機と違うときは座席番号の直接入力が使えます
- 一覧にない機材は「その他の機材」で、並び（3-3、2-4-2 など）と列数を指定すれば座席表が作れます
- 窓の判定は機材の仕様ごとに保存され、座席を選ぶ画面と窓位置タブの両方に反映されます

## 更新するとき

ファイルを書き換えて push したら、`sw.js` 冒頭の `CACHE = "skylog-v1.3.0"` の数字を上げてください。上げないと古い画面がキャッシュに残ります。

## 注意

- Safariのプライベートブラウズでは保存できません
- 端末のデータはときどき 設定 → バックアップ → 書き出す で控えを取っておくと安心です（機種変更時もこのファイルで移せます）
